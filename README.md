# blog-to-pdf-guide

Turns blog posts the user already wrote into a give-away PDF guide for growing an email list: 5 to 7 chapters in a logical order, repeats cut, a checklist after each chapter, title and contents pages and a final call to action, in the author's voice.

It asks the questions your material leaves open (each with a default) before it builds anything, then runs a "Done means" check and reports the result.

## Install

- Upload `blog-to-pdf-guide.zip` in your Claude skills settings, or
- Copy this folder into `~/.claude/skills/blog-to-pdf-guide/` (Claude Code), or
- `npx skills add arm-pz/blog-to-pdf-guide`

Check: start a new session and confirm `blog-to-pdf-guide` appears in the skill list.

## Try it

- "Turn my blog posts into an ebook I can give away."
- "Compile these 6 articles into a free guide for my newsletter signup."
